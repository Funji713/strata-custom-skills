# Conflict Resolution Prompt

When sources disagree, do not silently overwrite either source.

1. Record all candidates.
2. Identify evidence type and context for each candidate.
3. Prefer evidence that best describes the specific question being resolved (for example active runtime configuration for deployment behavior, method prose/figure reconciliation for research sequence).
4. Resolve only when evidence is sufficiently strong.
5. Otherwise mark the conflict `unresolved`.
6. Record the resolution basis explicitly.
7. Never convert unresolved information into a verified diagram element.
