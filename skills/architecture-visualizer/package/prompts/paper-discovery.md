# Paper Discovery Prompt

Goal: identify the minimum high-value evidence needed to understand the paper's method.

Prioritize: title, abstract, contribution statements, method/proposed method, figures and captions, model/framework sections, experiment setup, results, conclusion.

Track text, figures, captions, equations, and tables separately. If a figure and prose appear inconsistent, preserve the disagreement for conflict resolution. Related work is low priority unless required for interpretation. Output only fields valid under `source-index.schema.json`.
